# 论文素材

- `paper.pdf`：TransfHAR 原论文（arXiv:2608.15861v2）的本地副本，用于核对原文和重建页面截图。
- `figures/fig1–8.webp`：论文图 1–8，从原文裁切后统一转为 WebP（q92）。
